# 学校通 · SchoolSift 设计依据

每个功能都对应调研报告(`C:\claude\app-pain-research\差评里的App机会.html`,线上版 [claude.ai/artifact/TpPsZdS88vZk4enQDDcYe9](https://claude.ai/artifact/TpPsZdS88vZk4enQDDcYe9))里的一个痛点编号。没有编号的功能不做。

## 依据的痛点

| 编号 | 痛点(报告原文摘要) | 用户原话 |
|---|---|---|
| **F01** | 学校通知轰炸:每封邮件都是一个任务,没人帮你转成日程。Ohai $15–40/月且无日程总览;学校 App 无搜索、图片通知搜不到 | "47 notices from the 7 teachers… in just the past 3 days" |
| **F02** | 学校沟通渠道碎片化,信息搜不到;学校指定、家长无选择权;多孩多校无法筛选 | "I can't stand parent square!" |
| **F03** | 心智负担集中在一个家长身上,共享日历也分担不了;工具不会主动催,也不会追踪是否完成 | "When are they gonna build that AI for moms?" |
| **F04** | 家庭日历突然收费:Cozi 只能看 30 天、小组件收费;原本免费的核心功能被锁;广告 | "7 years… now… pay 40 a year… schedule anything 30 days out" |
| **F05** | 另一个人就是不用共享工具;要求每个人安装+注册 | "my sibling wouldn't use it" |
| **I07** | 截图/短信/邮件里的活动要手动重打进日历 | "frustrating to not be able to add screenshots to manual calendar" |
| Part 4 Idea #1 | 家校通:转发/截图/纸质照片 → 提取事件、截止、要签的表、要交的钱,带置信度并标出改期 → 按孩子分组 → 指派给伴侣并持续提醒 → 同步到家长自己的日历 | — |
| Part 5 品类 A「义务收件箱」 | 跨来源的截止日期捕获层:AI 抽出"谁、要做什么、什么时候之前",写进日历/提醒,**持续追踪直到用户确认** | — |
| Part 5 品类 C「免安装协作」 | 参与者只需收到一条短信 / WhatsApp / 网页链接就能参与;只需要组织者一个人付费 | — |
| Part 5 品类 D「信任优先定价」 | 原本免费的核心动作永远免费;数据归用户、本地优先、随时可导出 | — |

## 功能 ↔ 痛点

| 功能 | 在哪 | 对应痛点 | 怎么回应 |
|---|---|---|---|
| 粘贴文字 / 拍照 / 相册 / 截图 / PDF 一并录入 | 通知 → 新通知 | F01、I07、品类 A | 信息以什么形式来都接,不要求家长先手抄 |
| 本机 OCR(Web: Tesseract.js;Android: ML Kit) | 新通知 → 识别图片文字 | I07、隐私约束 | 没 key 也能把照片变文字;图片不离开设备 |
| 规则解析器(中英文日期/时间/地点/金额/签字/缴费/带东西/截止/改期) | `core/notice_parser.dart` | F01、Idea #1 | 离线、确定性、可测试;每条带置信度和来源句 |
| 用家长自己的 Claude API key 做 AI 抽取(文字 + 图片 + PDF) | 设置 → AI;新通知 → 用 AI 识别 | F01、Idea #1「AI 可以做什么」 | 复杂通知、手写、表格交给模型;同样返回带置信度的结构,确认页不区分来源 |

| 今日页「今天和明天」+「要家长办的事」(逾期置顶)+ 待确认通知 | 今日 | F01(无日程总览)、F03 | 一屏看完,不用翻 47 条 |
| 多孩子各自颜色,全局按孩子筛选 | 顶部筛选条 | F02「多孩多校无法筛选」 | — |
| 成绩按孩子/科目/日期 + 趋势图 + 班均 | 成长 → 成绩 | 用户需求(MVP 第 4 条) | 纯本机,不与任何平台同步 |

## 有意不做的(报告与用户约束都指向不做)

- **Gmail / Outlook 授权读信**:Google 受限权限要过安全审计,MVP 用「粘贴 / 转发文字 / 截图」替代;等有 15 个真实家庭跑通两周再考虑。
- **账号系统与云同步**:违背本地优先与儿童隐私约束;家庭成员同步暂靠 JSON 备份 + 「发给家人」。
- **学校端功能**:定位是坐在学校 App 之上的家庭作战室,不替代 ParentSquare / ClassDojo。
- **网页推送通知**:需要推送服务器;网页版只在页面打开时提醒,后台提醒请用 Android 版。

## 借鉴与避开

| 来源 | 借鉴 | 避开 |
|---|---|---|
| Cozi | 家庭共享日历、按成员着色 | 30 天限制、小组件收费、广告(F04) |
| Ohai | 转发 / 拍照 → AI 提取 | 每月 $15–40 订阅、没有日程总览(F01) |
| ParentSquare / ClassDojo | 按班级/孩子分组的通知流 | 不能搜索、通知轰炸、问卷弹窗、要求家人都注册(F02、F05) |
| Skylight / FamilyWall | 「今天」一屏总览 | $300 硬件、订阅(F04) |

## 技术栈说明(为什么不是 React + Vite + Capacitor)

用户建议的 PWA + Capacitor 方案完全可行;选择继续 Flutter 的理由:

1. 0.1 版已经用 Flutter 建成并上线(Web + Android 一份代码),改栈等于重写。
2. 用户机器上已有完整 Flutter / Android 工具链和上架经验(知命 App 同一条流水线)。
3. 同一代码日后可出 iOS、Windows;Capacitor 路线要再加一层壳。
4. 约束里的每一项都在 Flutter 里有等价物:IndexedDB → Hive CE(Web 端就是 IndexedDB);Tesseract.js → Web 端通过 JS 互操作直接用 Tesseract.js,Android 端用 ML Kit 端侧模型(比 Tesseract 准);Claude API → 原生 HTTP 直连(Dart 无官方 SDK)。
