老师、学校、班级群发来一堆通知,哪天活动、哪张单子要签、哪笔钱要交,总要有人一条条记下来。学校通帮你读懂通知,把要做的事分派下去,并一直追踪到做完。

【通知 → 日程和待办】
• 粘贴文字,或拍照、从相册选图、截图、PDF 导入
• 在手机上离线识别图片文字(Google ML Kit,图片不上传)
• 自动找出:活动日程、签字回执、缴费、要带的东西、截止日期,每条都标出把握度和原句,由你核对后一键写入
• 识别"改期 / 取消",自动更新之前的日程
• 原文永久保留、全文可搜、按孩子筛选
• 可选:填入你自己的 Claude API key,让 AI 读文字、图片和 PDF(只在你点按钮时发送这一条通知)

【日程与待办】
• 月历 + 接下来 30 天,按孩子着色,指派给爸爸或妈妈
• 签字类有「待签 → 已签 → 已交回」三种状态
• 导出 .ics,或一键加到 Google 日历;一键把今日简报、日程发给家人

【提醒】
• 截止前一天晚上 7 点、当天早上 8 点提醒;逾期后每天再提醒,最多 7 天
• 日程前一天和开始前 1 小时提醒;每天早上的简报

【成长记录】
• 测验成绩:按科目看趋势,可对比班级平均
• 每日学习记录:作业、阅读分钟、专注度、老师反馈,连续打卡
• 签字袋:纸质回执拍照存档,追踪到交回

【用英文回复老师】
用中文写要点,选好写给谁和语气,生成得体的英文邮件或短信,并附中文回译,确认意思没变。需要你自己的 Claude API key。

【家庭同步(可选)】
用邮箱注册并创建家庭,再用邮箱邀请家人。之后爸爸妈妈各用自己的账号看到、修改同一份数据,实时同步;家庭成员权限完全相同。可以随时退出家庭,也可以在应用内删除账号。

【你的数据归你】
• 不开家庭同步时,数据只存在你的手机上,不需要注册
• 没有广告,没有统计 SDK
• 随时导出 JSON 备份(含照片)和 CSV
• 中文 / 英文界面
